About Student Hub Portal

Student Hub Portal is a simple web application developed to help students manage their academic information in one place. It provides easy access to important services such as student profiles, admin information, events, feedback, FAQs, and contact details.

The main objective of this portal is to make student information easily available and improve communication between students and the college. Students can quickly view their details, check upcoming events, submit feedback, and contact the college through this portal.

This project is developed using HTML and CSS as part of learning web development. It demonstrates a basic student management system with a clean, user-friendly interface.
